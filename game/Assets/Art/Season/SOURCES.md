# Season cosmetic sources

Downloaded 20 September 2026. All selected source pages explicitly declare CC0, permitting commercial use and modification without required attribution.

- Cap.fbx / TopHat.fbx: Teh_Bucket, https://opengameart.org/content/hats-clothing-props . Individual snapback_e.zip and top_hat.zip downloads. Only meshes; none of the packaged textures, logos or Unity packages are used.
- Crown.fbx: BullHornGames, https://opengameart.org/content/low-poly-crown . lowPolyCrown.zip, creator reports 208 triangles.
- light_01.png / star_01.png / trace_01.png: Kenney Particle Pack, https://kenney.nl/assets/particle-pack . Kenney, CC0.
- License terms: https://creativecommons.org/publicdomain/zero/1.0/ ; retain this source record with derivatives.

Archive hashes and reward mapping: docs/SEASON_PASS_ASSETS.md. Generated fitted accessory prefabs and meshes use the source geometry with Veyro materials.

The 23 UI sprites in `Assets/Resources/Art/CosmeticThumbnails/` are baked derivatives of
the same runner, accessories and original cosmetic finishes/effects, generated by
`CosmeticThumbnailBuild.Generate`. Runner source: Kenney Animated Characters 3 (CC0),
as documented in `docs/GAME_ART.md`. The reference screenshots inform layout only;
no Rocket League or Pokemon Go artwork is included.
