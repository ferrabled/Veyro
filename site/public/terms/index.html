2. The game

Veyro Run is a motion-controlled endless runner for Android. Every run plays fully offline, it requires no sign-in, and it shows no advertising. Versions that include the in-game shop (September 2026 onward) go online to check which cosmetics your device owns, and buying or restoring one needs a connection too (section 3, and the privacy policy for what is sent). Versions with the shared leaderboard (the leaderboard update onward) additionally create an anonymous player profile — a random ID and a generated display name, nothing typed by you — and upload finished-run results so the public leaderboards work; you can rename it freely and delete it in the game at any time (see the privacy policy and data deletion). Versions with notification settings use OneSignal for registration and delivery; versions with GAMEPLAY ANALYTICS offer a separate opt-in Layers service. The privacy policy explains these controls and processing. Without a connection the game stays fully playable — cosmetics you already own normally remain available from the device's saved copy, up to eight of the most recent pending runs are queued locally for later upload (older pending runs are discarded when the queue is full, and uploads remain subject to server validation and submission limits), and anything you don't own shows as locked. Earlier closed-beta versions have no shop and never go online. Features may change, be added, or be removed between versions.
