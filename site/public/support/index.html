Support

Veyro Run (com.ferrabled.veyro.run) · answered by the developer

Fastest way to reach us: ferrabled+veyro@gmail.com. It's a one-person studio — you'll get a reply from the person who wrote the code.

Does the camera record me?

No. Camera frames are processed in memory on your phone by a local model and immediately discarded — never recorded, never saved, never transmitted. Nothing the camera sees ever touches the network. The game does go online for cosmetics — checking which ones you own at launch, and buying or restoring one — and no camera data is involved in any of that. Details in the privacy policy.

Camera mode isn't detecting me well

Camera mode is in beta. What helps: prop the phone upright at roughly chest height 1–2 meters away, face the front camera, and make sure your face is reasonably lit. If it still misbehaves, tilt & touch mode is always available — and a report to the email above (phone model + what happened) genuinely helps fix it.

Does it work offline?

Yes — the whole game plays offline. The Daily Run is computed from the date on your device, with no server involved, so everyone gets the same track without the game going online. In versions with the shop, the game asks our purchase provider on launch which cosmetics your device owns, and buying or restoring one needs a connection because Google Play handles it. In versions with the shared leaderboard, finished runs upload automatically — and up to eight of the most recent pending runs are kept on the device for upload when a connection returns. Older pending runs are discarded when the queue is full, and uploads remain subject to server validation and submission limits; the leaderboard card just shows sample data until then. With no connection nothing breaks — cosmetics you own normally stay available from the on-device copy, anything you don't own stays locked, and every run still plays. What goes over the network is in the privacy policy.

How do I join the closed test?

Email ferrabled+veyro@gmail.com with the subject "Veyro Run closed test" from the Google account you use on your Android phone, and you'll receive an opt-in link.

Purchases and refunds

Starting with the September 2026 update, the game has optional cosmetic purchases in its SHOP tab. Everything buyable is cosmetic, nothing gives a gameplay advantage, and the free download is the complete game. Earlier beta versions have no shop at all — if you don't see a SHOP tab, you're on one of those. Payment is processed by Google Play under your own Google account; we never see your card details. Refunds follow Google Play's refund policy; if something goes wrong, email us and we'll help sort it out.

I bought a skin and it's not there

Open the game, go to the SHOP tab on the main menu, and tap RESTORE PURCHASES — signed in to the same Google account you bought with — unlocks are tied to that account and come back on any device it's on. (After a run, the result screen's SHOP button lands on the same tab.) Restoring needs a connection. If it still doesn't appear, email us with your order number from your Google Play order history and we'll fix it.

What's the leaderboard profile? Do I have an account?

Versions from the leaderboard update onward create an anonymous player profile the first time the game goes online: a random ID and a generated name like SWIFT-FOX-42 — no sign-in, no email, nothing typed by you. Finished runs upload automatically so the daily and all-time boards work; your generated name and scores are what other players see. Tap new name on the PROFILE tab as often as you like. Details in the privacy policy; deleting it is below.

Will my profile survive a reinstall or a new phone?

Usually, yes on the same device: the game stores a recovery code that Android's automatic backup carries across a reinstall, and your profile — name, progress, leaderboard entries — comes back on the next launch, along with your purchases (those are restored separately through Google Play and always come back). For a new phone, or if device backup is off: the PROFILE tab shows your recovery code with a tap-to-copy — store it somewhere safe, and on the new install use IMPORT PROFILE with that code before playing any runs. Without the code and without a backup, the old profile cannot be recovered — there's no login to prove it was yours; a fresh profile starts instead. Purchases still come back either way. Treat the code like a key: anyone holding it can claim the profile, and every successful import issues a fresh code (the old one stops working).

Notifications

In versions with PROFILE → NOTIFICATIONS, allow or turn off Android notifications there. The full game works without them. Turning them off stops delivery but does not delete OneSignal's notification record or stop registration/session processing while using the app. Your profile database stays in Supabase; Firebase Cloud Messaging only delivers Android notifications.

Gameplay analytics

In versions with PROFILE → GAMEPLAY ANALYTICS, analytics is off until you enable it. It helps us understand visits, notification opens and run results. It includes pseudonymous installation IDs, device/app details, SDK delivery diagnostics and country/region derived from IP, but never camera frames or motion readings. TURN OFF withdraws consent and shuts the SDK down, so nothing further is sent; events still unsent stay on the device and are deleted when you next enable analytics or clear app data. This is separate from notifications; the whole game works with analytics off. Details are in the privacy policy.

Data deletion

Analytics records are separate. To request deletion of data already delivered to Layers, copy PROFILE → GAMEPLAY ANALYTICS → COPY ANALYTICS SUPPORT ID and email ferrabled+veyro@gmail.com. Turn analytics off to stop further collection. The ID locates records; we verify control before deleting. Requests are handled within 30 days, normally sooner. DELETE ONLINE PROFILE does not delete this separate record.

Notification records are separate in the first notification-enabled version. Copy PROFILE → NOTIFICATIONS → COPY NOTIFICATION SUPPORT ID, then email the support address below to request deletion of that OneSignal record. The ID locates it; we verify control before deleting. DELETE ONLINE PROFILE does not delete the separate notification record. Requests are handled within 30 days, normally sooner; using the app after deletion can create a new notification record.

In versions with the online profile (the leaderboard update onward), the fastest way to delete profile-related records is in the app: PROFILE tab → DELETE ONLINE PROFILE → tap again to confirm. Deletion is immediate and permanent: the profile, its generated name, every uploaded run and every leaderboard entry are erased, the recovery code is removed from the device, and a deletion request is sent to our purchase provider RevenueCat for the same identity. What remains afterwards: your local device stats (best scores, streak, history — on your device only, removed by clearing the app's data or uninstalling), and any purchase in your own Google Play order history (Google's record, which we cannot delete — restoring purchases on a later install can therefore recreate a purchase record with our provider).

Without the app installed: email ferrabled+veyro@gmail.com with the subject "Veyro Run data deletion". The PROFILE tab shows two things worth copying somewhere safe while you still have the app: your Player ID (locates your records) and your recovery code (proves they're yours — only your device ever held it, the server keeps just a fingerprint of it). Sending the recovery code with a deletion request is the strongest proof possible, and since the account is being deleted, the code dies with it. With only a Player ID we will ask for another way to demonstrate control before deleting — or reinstall briefly and use the in-app path, which needs no proof because the profile itself is the proof. Requests are handled within 30 days, normally much faster.

If you can't provide a Player ID or recovery code and the profile can't be identified another way, we honestly cannot tell which profile is yours — that's the flip side of a no-login game. Profiles are pseudonymous, not anonymous: records attached to an ID are treated as personal data and deleted on a verified request, we just need a way to find them.

Versions without the online profile: there is no account to close. Local game data lives on your device and is removed when you uninstall (Android's automatic backup may restore it on reinstall, depending on your settings). For the shop's RevenueCat record in those versions, email us — include your Google Play order number if you bought something so the record can be found.
