## Processing

SFX: downmixed to mono, resampled to 44.1 kHz, leading silence below −50 dBFS and trailing silence below −60 dBFS removed, then a single gain so RMS sits at about −16 dBFS without the peak exceeding −1 dBFS (long-decay jingles end up peak-bound at −1 dBFS). The crash is the one exception, on purpose — it is the cue that must stand out on a phone: the three layers are mixed, normalised, driven +18 dB into a −0.5 dBFS limiter (0.5 ms attack, 40 ms release), then the Vorbis file is decoded and re-gained once so the *decoded* peak is −0.5 dBFS (the encoder overshoots a brick-walled signal by about 1 dB). It ends at −14.8 dBFS RMS (−13.5 LUFS; the UI cues sit at −16 dBFS, the foley swishes at −23 to −26) with its first 100 ms still ~7 dB above the tail, so it reads as a hit, not a wall. Music: no resampling beyond the container, gain-only to −14 LUFS integrated (measured −14.0 to −14.1, true peak ≤ −0.4 dBTP); `result_lost` is the one track that is cut, at a bar boundary, with 3 ms edge fades. No reverb, EQ or pitch changes anywhere; `coin` is pitch-varied at runtime by code, not in the file.

The `Licenses/` folder is under `Resources/`, so Unity ships those seven small text files (about 3.5 KB) as TextAssets; that is the price of keeping the licences beside the audio as the art folders do. The OpenGameArt sources ship no licence text of their own; their bullets above (URL, licence field, date, archive hash) are the record.

## How to swap a sound

Drop a file with the same name (`Sfx/coin.ogg`, `Music/run_02.ogg`, …) over the existing one — mono 44.1 kHz for SFX, stereo 44.1 kHz for music, both Ogg Vorbis — and Unity reimports it; the code loads by name and the `AssetPostprocessor` in `Assets/Editor` applies the import settings, so no `.meta` edits are needed. Add a bullet above with the source URL, licence and date checked before committing it.
